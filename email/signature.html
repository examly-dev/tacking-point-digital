Tacking Point Digital signature

Built for Gmail: tables, inline styles, Arial. Gmail cannot load Satoshi, so this is what recipients will actually see.

  1. Select the signature in the grey box below — Andy through the website.
  2. Copy. On a Mac that is ⌘C.
  3. In Gmail: Settings (gear) → See all settings → General → Signature. Create one named Tacking Point Digital.
  4. Paste into the signature box.
  5. Set “Insert signature before quoted text” on, then Save changes.
